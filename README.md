
# Simple Calculator

## Description
A simple calculator built with Python.
It takes two numbers and an arithmetic operator from the user and calculates the result.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero handling

## Concepts Learned
- Functions
- Parameters
- Return statements
- Conditional statements
- Float data type
- User input

## Example

Input:
15
*
4

Output:
Result: 60.0

## How to Run

Run the following command:

python simple_calculator.py

- Python 3
- PyCharm
